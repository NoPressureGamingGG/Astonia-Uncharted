# Server 3 Roadmap

## Phase 0 — Establish the baseline

- [x] Identify Server 3 as the primary ruleset.
- [x] Configure Ubuntu WSL build dependencies.
- [ ] Produce and record the first successful local server build.
- [ ] Start a disposable development database and verify account creation.
- [ ] Verify a local client can connect.

## Phase 1 — Map the living game

- [ ] Inventory server mechanics, configuration, zones, drivers, data, and code.
- [ ] Map important mechanic interactions and identify possible conflicts.
- [ ] Ask the project owner for gameplay context whenever code alone is unclear.
- [ ] Audit PathOfAstonia for reusable ideas, with provenance notes.
- [ ] Define the first player-facing design goal and acceptance criteria.

## Phase 2 — First controlled reimagining

- [ ] Implement one isolated, purposeful change.
- [ ] Test it on the disposable development database.
- [ ] Document behavior, configuration, and rollback.

## Future — Modernization and Server 35

- [ ] Evaluate a 64-bit migration with compatibility and deployment risks.
- [ ] Compare Server 3 and Server 35 mechanics rather than merge code.
- [ ] Choose a port strategy after Server 3 has a stable, tested feature set.
